# Design Library

A private, local library of website design styles. Browse by **category** (chips with counts), narrow by plain-language
**vibe**, search by keyword, and open any design for its palette, fonts, build notes, references and a live mockup.

No dependencies, no install step. Needs Node 18+ (or just Python for a plain static server).

## Run

```bash
npm start            # builds data/designs.json, then serves http://localhost:4610
```

Other ways:

```bash
npm run build                     # only merge + validate data (prints warnings, never fails)
PORT=4700 npm start               # different port
python3 -m http.server 4610       # no Node needed; then open http://localhost:4610/site/
```

Everything is served from the repo root, so the viewer lives at `/site/` and `/` redirects there.
If you use another static server, serve the repo root (not `site/`) and open `/site/`.

## Using the viewer

* **Category chips** `ALL 48`, `PRINT-TECH PAPER 4`, ... Counts follow the active vibe and search filters.
* **Vibe chips** are multi-select. When two or more are on, a small `any / all` switch picks OR or AND matching.
* **Search** looks at names, descriptors, summaries, keywords, vibes, best-for and fonts. Press `/` to focus it.
* **Links are shareable**: `#all`, `#print-tech-paper`, `#print-tech-paper/stillpage-halftone`,
  `#all?q=serif&v=dark,editorial&m=all`.
* **Detail view**: click a card. `←` / `→` step through the current results, `Esc` closes, swatches copy their hex on click,
  "Open live mockup" swaps the screenshot for the real HTML page scaled from 1280px.

## Add a design

1. **Mockup**: create `designs-src/<design-id>/index.html`, a self-contained 1280x800 hero (inline CSS/SVG, no external images).
2. **Screenshot**: `npm run screenshot -- <design-id>` writes `assets/designs/<design-id>.png` (1280x800).
   With no ids it re-shoots every folder in `designs-src/`. Needs Playwright (`npm i -D playwright`, or set `PLAYWRIGHT_PATH`
   to a `node_modules` directory that contains it).
3. **Data**: add an entry to `designs` in `data/designs/<category-id>.json`. To start a new category, create that file with a
   `category` block and 4-5 designs.
4. `npm run build` (or just `npm start`) and read any warnings it prints: missing images or mockups, vibes outside the
   vocabulary, duplicate ids, wrong keyword counts.

Schema, field rules and the fixed vibe vocabulary are in [`docs/SPEC.md`](docs/SPEC.md).

## Layout

```
data/designs/<category-id>.json   source of truth, one file per category
data/designs.json                 generated by scripts/build-data.mjs (don't edit)
assets/designs/<id>.png           screenshots
designs-src/<id>/index.html       mockups
site/                             the viewer (index.html, style.css, app.js)
scripts/build-data.mjs            merge + validate
scripts/serve.mjs                 zero-dependency static server
scripts/screenshot.mjs            Playwright re-shooter
```
